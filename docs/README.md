# docs

Durable project record — not code, not chat history. Three kinds of files live here:

- **`decisions.md`** — the running "rules of working": conventions and calls
  we've made that should hold for the rest of the project unless explicitly
  revisited. Read this before making a choice that might already be decided.
- **`roadmap.md`** — what's done, in progress, and planned, across the whole
  Blackbox project (job portal, rankings, NGO site, agents).
- **`plans/`** — one file per feature/initiative plan, written before
  building it. A plan here means "this is the approach we agreed on," not
  "this is finished" — check `roadmap.md` for status.
